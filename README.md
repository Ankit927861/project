# StudyFlow

StudyFlow is an Alexa+ inspired student productivity assistant
built for the Amazon Developer Hackathon.

## Features

- Add study tasks
- Create study plans
- Explain learning topics
- Provide study advice
- MCP-based tool interface
- Streamable HTTP MCP transport

## Technology

- Python
- Model Context Protocol (MCP)
- Streamable HTTP
- FastMCP

## Project Status

Prototype - built during the Amazon Developer Hackathon 2026.
